# 👑 Casino Prince Character Animation

A 2D **casino prince character animation** created for a casino-themed game project.

The character artwork was **AI-generated** and used as the visual foundation for the project. I worked on bringing the character to life through 2D animation while maintaining the original character design and visual style.

## 🎬 Animations

The project includes two character animation states:

* 🧍 **Idle** — A subtle idle cycle that gives the character natural movement and presence.
* 🦘 **Jump** — A dynamic jump animation featuring anticipation, takeoff, airborne movement, and landing.

## 🎨 Character

The original casino prince artwork was **generated using AI tools**.

The AI-generated character was then prepared and animated as part of the 2D animation workflow.

## 🛠️ Animation Focus

This project demonstrates:

* 2D character animation
* Idle animation
* Jump animation
* Character posing
* Timing and spacing
* Anticipation and follow-through
* Secondary movement
* Maintaining character proportions during animation
* Working with AI-generated character artwork

## 🎰 Game Context

The character was designed for use within a **casino-themed game**, where character animation helps add personality and visual interest to the overall game experience.
